# Эмулятор виртуальной файловой системы (VFS Emulator)

Проект создан для эмуляции работы файловой системы в памяти.
Поддерживаются базовые команды:

- `ls` — вывод содержимого директории
- `cd` — смена каталога
- `cat` — чтение файла
- `chown` — смена владельца
- `rmdir` — удаление пустой директории

## Этапы проекта
1. **Stage 1** — минимальный CLI-прототип
2. **Stage 2** — поддержка параметров запуска и стартового скрипта
3. **Stage 3** — полноценная VFS из CSV (в памяти)
